## Project Overview

Customer churn is a major problem for service-based businesses. In this project, we analyze the **Telco Customer Churn** dataset to:
1. **Clean & Preprocess Data:** Handle missing values, scale numerical features, and encode categorical variables.
2. **Perform Exploratory Data Analysis (EDA):** Visualize churn distributions and feature correlations.
3. **Handle Class Imbalance:** Utilize SMOTE (Synthetic Minority Over-sampling Technique) to ensure the models do not become biased toward the majority class.
4. **Train & Tune Models:** Build Logistic Regression and Random Forest classifiers, and rigorously tune them using **GridSearchCV** for optimal hyperparameters.
5. **Evaluate Models:** Assess performance using Precision, Recall, F1-Score, ROC-AUC, and Confusion Matrices.
6. **Extract Business Insights:** Identify the top factors contributing to churn and formulate actionable retention strategies.

## Repository Contents

* `churn_analysis.py` - The main Python script that executes the end-to-end machine learning pipeline, including data cleaning, SMOTE, GridSearchCV tuning, and evaluation.
* `dashboard.py` - An interactive **Streamlit Web Dashboard** providing a clean UI for stakeholders to view the data and visualizations.
* `Telco-Customer-Churn.csv` - The real-world dataset used for analysis.
* `business_recommendations.md` - A detailed report on model evaluation, feature importance, and practical business recommendations to reduce churn.
* `*.png` - Various visualizations generated by the script, including confusion matrices and feature importance bar charts.

## Setup & Installation

1. Clone this repository to your local machine.
2. Ensure you have Python installed.
3. Install the required dependencies:
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn imbalanced-learn streamlit
   ```

## Usage

**To run the core Machine Learning Pipeline:**
```bash
python churn_analysis.py
```
This will train and tune the models, output evaluation metrics to the console, and generate the visualization plots in the same directory.

**To run the Interactive Web Dashboard:**
```bash
streamlit run dashboard.py
```
This will launch a local web server and open the dashboard in your browser.

## Results Summary

* **Logistic Regression (Tuned)** was the preferred model, achieving a strong **ROC-AUC** and **Recall**, successfully identifying the majority of actual churners.
* The top factors driving customer churn are **Tenure** (newer customers leave faster), **Total/Monthly Charges** (expensive plans increase churn), and **Payment Method** (Electronic checks correlate with higher churn). 
* Recommended retention strategies include incentivizing long-term contracts, targeting newer customers with enhanced onboarding, and encouraging automated payment methods.
